# Bayou & Blazer — Company Documents

The three living reference documents for the app, kept alongside the code
so they version with it. Each is a standalone HTML page: open it in a
browser, or attach the file directly to a Claude chat to work on it there.

| Document | File | What it covers |
| --- | --- | --- |
| **Business Playbook** | [`business-plan.html`](./business-plan.html) | Revenue model, Houston go-to-market, store partnerships, legal/IP (including the persona-name flag), valuation, and expansion economics. |
| **Back of House Review** | [`back-of-house-review.html`](./back-of-house-review.html) | The agent team's architecture decisions: how the agents communicate, what was built in the engine room, and which ideas were rejected for latency. |
| **Architecture & Feature Reference** | [`architecture.html`](./architecture.html) | The final build record: every agent, feature, and data system; the measured latency budget; quality machinery; the city-pack playbook and the women's application plan. |
